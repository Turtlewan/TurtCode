# L0 — Read Only

## Allowed
- Read any file
- Search codebase (Grep, Glob)
- Explain code
- Draft plans and specs
- Generate recommendations

## Forbidden
- Write any file
- Run any shell command
- Make any git operation

## Approval gate
Every action confirmed manually before execution.

Unfamiliar codebases, sensitive production audits, learning sessions,
situations where you want full visibility before anything changes.
