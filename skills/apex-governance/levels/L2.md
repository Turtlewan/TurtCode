# L2 — Controlled Auto-Write (default)

## Allowed
- All L1 actions
- Write non-critical files without per-file confirmation
- Run: npm install, npm run build, npm run lint, npm test

## Forbidden (require explicit confirmation)
- Writing critical files: *.env, migrations, auth middleware, CI/CD configs
- Schema changes
- Any git operation

## Critical files (always require confirmation at this level)
*.env, *.env.*, prisma/migrations/**, src/middleware/auth*, .github/workflows/**

## Approval gate
Automatic for non-critical files.
Explicit gate for critical files:
⚠️ Write [L2 gate — critical file]: prisma/migrations/0001_init.sql — Approve? [y/n]

## Suitable for
Day-to-day feature development. The default for most sessions.

## Rollback
git diff to review, git checkout to revert before commit.
