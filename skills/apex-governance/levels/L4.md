# L4 — Agentic Loop

## Allowed
- All L3 actions (confirmation gates still active for critical files and commits)
- git commit with drafted message — user approves message before commit executes — integration-branch commits; transient worktree task-branch commits are build mechanics, ADR-046 D1

## Forbidden
- git push (any branch, any remote)
- git merge — except the named-PR carve-out (D2, ADR-046; apex-governance § Hard blocks)
- PR creation
- DROP TABLE or any destructive schema operation
- Deleting files or git branches — except a spec-listed `Operation: delete` on a non-critical path (D7, ADR-046) and post-integration teardown of a branch you created (D8, ADR-046 § D8); see apex-governance § Hard blocks
- Accessing production environment directly

## Approval gate
Commit message approval:
The gate governs integration-branch commits; transient worktree task-branch commits are build mechanics (ADR-046 D1).
⚠️ git commit [L4 gate]
  Files: {list of staged files}
  Message: "feat: {description}"
  Risks: {what changed}
  Rollback: git reset HEAD~1 (before push)
  Approve message? [y / n / edit]

## Audit
Full session audit log required: docs/audit/YYYY-MM-DD.log **Who writes it (D5, ADR-046):** append-only is the sanctioned mode and editing or deleting an existing entry is permanently forbidden — but the live classifier refuses every `docs/audit/` path on a path match alone, so **the agent does not write this file**. Until the classifier follow-up ships, these appends route through the host.

## Suitable for
Solo projects, personal tools, high-trust internal work where you review commits yourself.

## Rollback
git reset HEAD~1 (before push — always safe at this level).
