# L5 — High Autonomy

## Allowed
- All L4 actions
- git push to non-main, non-master branches
- Create draft PRs (description requires approval before creation)

## Forbidden (hard blocks — cannot be overridden)
- git push to main or master
- Merge any PR
- Approve any PR
- Delete any branch
- Modify production infrastructure
- Access production data or secrets

## Approval gate
PR description approval before creation:
⚠️ Create draft PR [L5 gate]
  Branch: {branch} → main
  Title: {title}
  Description: {body}
  Approve? [y / n / edit]

## Audit
Full session audit log required: docs/audit/YYYY-MM-DD.log

## Suitable for
Solo projects where you review and merge PRs yourself before anything reaches main.

## Rollback
git revert {commit-sha} for pushed commits (creates new commit, safe on shared branches).
PR can be closed without merging.
