# L1 — Supervised Write

## Allowed
- All L0 actions
- Write files with per-file explicit confirmation

## Forbidden
- Running shell commands without confirmation
- Batch writes (multiple files in one approval)
- Schema or migration changes
- Any git operation

## Approval gate
Confirm each file before write:
⚠️ Write [L1 gate]: path/to/file.ts — Approve? [y/n]

## Suitable for
Production hotfixes, first session on a new codebase, high-stakes changes.

## Rollback
git checkout <file> for any confirmed write.
