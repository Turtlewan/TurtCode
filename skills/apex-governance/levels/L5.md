# L5 — High Autonomy

## Allowed
- All L4 actions (including the L4 commit gate: it governs **integration-branch** commits; transient `codex/<spec>-<task-id>` worktree commits are build mechanics — ADR-046 D1)
- git push to non-main, non-master branches
- Create draft PRs (description requires approval before creation)

## Forbidden (hard blocks — cannot be overridden) — subject only to the named ADR-046 carve-outs below
- git push to main or master
- Merge any PR — except a named PR under live user approval this session (D2, ADR-046; apex-governance § Hard blocks)
- Approve any PR
- Delete any branch — except post-integration teardown of a branch you created, both D8 checks passed (ADR-046; apex-governance § Hard blocks)
- Modify production infrastructure
- Access production data or secrets

## Approval gate
PR description approval before creation:
⚠️ Create draft PR [L5 gate]
  Branch: {branch} → main
  Title: {title}
  Description: {body}
  Approve? [y / n / edit]

## Audit
Full session audit log required: docs/audit/YYYY-MM-DD.log **Who writes it (D5, ADR-046):** append-only is the sanctioned mode and editing or deleting an existing entry is permanently forbidden — but the live classifier refuses every `docs/audit/` path on a path match alone, so **the agent does not write this file**. Until the classifier follow-up ships, these appends route through the host.

## Suitable for
Solo projects where you review and merge PRs yourself before anything reaches main.

## Rollback
git revert {commit-sha} for pushed commits (creates new commit, safe on shared branches).
PR can be closed without merging.
